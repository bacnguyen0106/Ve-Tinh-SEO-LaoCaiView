## 🚀 Hướng Dẫn Triển Khai Lên GitLab Pages:
1. Đăng ký/Đăng nhập tài khoản tại nền tảng `GitLab Pages`.
2. Tạo dự án mới và liên kết với thư mục này (`satellites/06-gitlab-nhadat-laocai`).
3. Chọn chế độ triển khai: **Static HTML / No Build Command**.
4. Website sẽ tự động hoạt động tại tên miền: `https://nhadatlaocai-review.gitlab.io`.
