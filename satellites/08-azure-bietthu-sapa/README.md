1. Đăng ký/Đăng nhập tài khoản tại nền tảng `Azure Static Apps`.
2. Tạo dự án mới và liên kết với thư mục này (`satellites/08-azure-bietthu-sapa`).
3. Chọn chế độ triển khai: **Static HTML / No Build Command**.
4. Website sẽ tự động hoạt động tại tên miền: `https://bietthunghiduongsapa.azurestaticapps.net`.
