# Top Homestay & Trải Nghiệm Săn Mây Sa Pa
Hệ thống website vệ tinh SEO cho **LaoCaiView.vn** vận hành trên nền tảng **Netlify**.

## 🚀 Hướng Dẫn Triển Khai Lên Netlify:
1. Đăng ký/Đăng nhập tài khoản tại nền tảng `Netlify`.
2. Tạo dự án mới và liên kết với thư mục này (`satellites/04-netlify-homestay-sapa`).
3. Chọn chế độ triển khai: **Static HTML / No Build Command**.
4. Website sẽ tự động hoạt động tại tên miền: `https://tophomestaysapa.netlify.app`.
