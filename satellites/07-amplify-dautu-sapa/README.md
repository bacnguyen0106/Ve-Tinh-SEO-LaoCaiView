# Kinh Nghiệm Đầu Tư BĐS & Homestay Sa Pa
Hệ thống website vệ tinh SEO cho **LaoCaiView.vn** vận hành trên nền tảng **AWS Amplify**.

## 🚀 Hướng Dẫn Triển Khai Lên AWS Amplify:
1. Đăng ký/Đăng nhập tài khoản tại nền tảng `AWS Amplify`.
2. Tạo dự án mới và liên kết với thư mục này (`satellites/07-amplify-dautu-sapa`).
3. Chọn chế độ triển khai: **Static HTML / No Build Command**.
4. Website sẽ tự động hoạt động tại tên miền: `https://kinhnghiemdautusapa.amplifyapp.com`.
