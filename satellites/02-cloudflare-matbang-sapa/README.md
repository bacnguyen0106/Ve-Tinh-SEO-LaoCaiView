# Cẩm Nang Thuê Mặt Bằng Kinh Doanh Sa Pa
Hệ thống website vệ tinh SEO cho **LaoCaiView.vn** vận hành trên nền tảng **Cloudflare Pages**.

## 🚀 Hướng Dẫn Triển Khai Lên Cloudflare Pages:
1. Đăng ký/Đăng nhập tài khoản tại nền tảng `Cloudflare Pages`.
2. Tạo dự án mới và liên kết với thư mục này (`satellites/02-cloudflare-matbang-sapa`).
3. Chọn chế độ triển khai: **Static HTML / No Build Command**.
4. Website sẽ tự động hoạt động tại tên miền: `https://matbangsapa-review.pages.dev`.
